# My Study Hub

A personal website for organizing university study. Every course is split into five sections:

- **Lectures**
- **Sections**
- **Tasks**
- **Quizzes**
- **Final project**

## Features

- Add as many courses as you need
- Add items with a title, an optional link and a note (or a due date for tasks, quizzes and the final project)
- Tick items off and track progress per course
- Works on phone and desktop, with light and dark mode
- No account and no server: everything runs in your browser

## How your data is saved

Your courses and items are saved in your browser's local storage, on the device you use. They stay after you refresh or close the page, but they do not sync between devices. Clearing your browser data erases them.

## Run it

Open `index.html` in any browser. No install or build step is needed.

## Publish it with GitHub Pages

1. Create a new public repository.
2. Upload `index.html` and this `README.md`.
3. Go to **Settings**, then **Pages**.
4. Under **Branch**, choose `main` and `/ (root)`, then click **Save**.
5. After a minute or two, your site is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The whole website (HTML, CSS and JavaScript in one file) |
| `README.md` | This guide |

# موقع المذاكرة بتاعي

موقع شخصي لتنظيم مذاكرة الجامعة. كل كورس بيتقسم لخمسة أقسام: المحاضرات، السكاشن، المهام، الكويزات، والمشروع النهائي.

## المميزات

- تضيفي أي عدد من الكورسات
- تضيفي عناصر بعنوان ولينك وملاحظة، أو تاريخ تسليم للمهام والكويزات والمشروع
- تعلّمي اللي خلصتيه وتتابعي نسبة التقدم في كل كورس
- بيشتغل على الموبايل والكمبيوتر، وفيه وضع فاتح وداكن
- من غير حساب ولا سيرفر، كل حاجة بتشتغل في المتصفح

## بياناتك بتتحفظ فين

بياناتك بتتحفظ في متصفحك على نفس الجهاز، وبتفضل موجودة بعد ما تقفلي الصفحة. لكنها مش بتتزامن بين الأجهزة، ولو مسحتي بيانات المتصفح هتتمسح.

## تشغيله

افتحي ملف `index.html` في أي متصفح، ومفيش حاجة تتثبت.

## نشره على GitHub Pages

1. اعملي repository جديد وخليه Public.
2. ارفعي `index.html` وملف `README.md`.
3. روحي **Settings** ثم **Pages**.
4. تحت **Branch** اختاري `main` و`/ (root)` ودوسي **Save**.
5. بعد دقيقة أو اتنين الموقع هيبقى شغال على الرابط `https://اسم-المستخدم.github.io/اسم-الريبو/`.
